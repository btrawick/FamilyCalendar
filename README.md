# FamilyCalendar

Mobile-first family activity calendar prototype for Mom, Dad, Alice (14) and Juliet (10).

## Prototype features
- Today, Week, Month and Family views
- Per-person colour coding
- Multi-person events and logistics
- Parent approval inbox for child requests
- Add-event flow with recurring-event options
- Responsive phone-first UI

## Run locally
```bash
npm install
npm run dev
```
